GUIDA ASTA CONTE — RC5 MODALITÀ ASTA COMPATTA

Questa RC mantiene tutti i contenuti della RC4 e riduce lo scorrimento nella scheda squadra.

Novità RC5:
- scheda squadra divisa in 5 linguette: Formazione, Rosa, Consigli, Mercato e Note
- una sola sezione visibile alla volta, senza pagina unica molto lunga
- barra delle sezioni sempre raggiungibile in alto durante la consultazione
- pulsante Salva compatto e flottante in basso a destra
- frecce squadra precedente/successiva nell'intestazione
- intestazione più compatta con allenatore e modulo
- filtri della rosa senza ricaricare la scheda e senza perdere modifiche non ancora salvate
- mantenuti formazione grafica, rosa completa, stelle Lista asta, consigli, piazzati, mercato e note
- cache PWA aggiornata alla RC5

Installazione:
1. estrarre lo ZIP;
2. caricare su GitHub tutti i file sostituendo quelli esistenti;
3. attendere il completamento di GitHub Pages;
4. aprire l'app e aggiornare la pagina;
5. se compare ancora la RC precedente, chiudere e riaprire l'app oppure cancellare una volta la cache del sito.

Test consigliato:
- aprire Atalanta;
- passare tra le cinque linguette;
- selezionare stelle nella Rosa;
- modificare un campo, cambiare linguetta e tornare indietro;
- salvare dal pulsante verde flottante;
- provare le frecce squadra precedente/successiva.
